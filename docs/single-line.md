# Единая линия и роли (пункт 1 раздела 13 ТЗ)

## Единая горизонтальная линия

Раздел «Продажи» показывает один горизонтальный канбан. Группы слева направо, порядок постоянный, даже если в группе нет карточек:

| Группа | Колонки |
| --- | --- |
| Продажи | Новая → Обработка → Заказ |
| Дизайн и согласование | Задача для дизайнера → Взял в работу → Макет готов → Согласование → Согласован |
| Типография | В работе → Готово |
| Широкоформатная печать | В работе → Готово |
| Вывески | В работе → Готово |
| Монтаж | К планированию → Запланирован → Готово |
| Завершение | Заказ завершён · Отказ |

Колонки цехов и монтажа пока пустые: карточки заданий появятся с пунктами 3 и 4 плана (три цеха, монтаж). У каждой группы свой
заголовок, у каждой колонки свой счётчик.

- **Ползунок сверху** закреплён над доской и двигается вместе с ней в обе стороны.
- **Колесо мыши** над доской двигает её вправо и влево; на краю доски колесо снова прокручивает страницу, поэтому страница
  не «залипает». Боковые жесты тачпада и колесо с Ctrl обрабатывает браузер.
- **Перетаскивание мышью** за пустое место (заголовок группы, промежутки) двигает доску. Карточка, кнопка и поле сохраняют своё поведение.
- **Телефон:** над доской переключатель групп, нажатие переходит к нужной группе; доску можно листать свайпом. В нижней панели
  появилась кнопка «Продажи».

## Роли

| Роль | Что видит и делает |
| --- | --- |
| Владелец | Всё: он держит каждую роль. Управляет правами |
| Руководитель офиса | Все сделки, заказы, аналитика, источники и партнёры; возвращает закрытые сделки в работу |
| Администратор | Признак учётной записи: настройка пользователей и их ролей |
| Менеджер | Все этапы и сделки коллег, передача в цех, оплаты |
| Дизайнер | Колонки «Дизайн и согласование» и сделки этих этапов, только на чтение (действия дизайнера добавляются пунктом 2) |
| Сотрудник цеха | Своя группа линии; одна роль на цех: Типография, Широкоформатная печать, Вывески |
| Монтажник | Группа «Монтаж» |

Роли хранятся в `staff_roles`, их выдаёт администратор или владелец в карточке пользователя (раздел «Пользователи»). Первая
зарегистрированная учётная запись становится владельцем. Права проверяет сервер (RLS и команды), интерфейс только скрывает лишнее:
дизайнер получает из базы только сделки этапов дизайна, цеха и монтажник сделок не получают.

При обновлении старые роли перенесены: руководитель продаж → руководитель офиса, сотрудник цеха и руководитель производства →
сотрудник трёх цехов, выдача и монтаж → монтажник, учётная запись администратора → владелец.
